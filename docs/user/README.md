# User Documentation

This folder contains user-facing documentation and manuals.

## 📚 Documentation

- **[User Manual](./USER_MANUAL.md)** - Complete user guide with step-by-step workflows for all platform features

## 👥 User Roles

The platform supports multiple user roles:
- **Entrepreneurs** - Create and manage startup profiles
- **Investors** - Browse startups and make connections
- **Admins** - Manage platform content and users

## 🎯 Getting Started

1. Register an account
2. Complete your profile
3. Verify your account (if required)
4. Start exploring the platform

For detailed instructions, see the [User Manual](./USER_MANUAL.md).
