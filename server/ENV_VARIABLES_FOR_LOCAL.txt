====================================
LOCAL DEVELOPMENT ENVIRONMENT
For XAMPP / Local Testing Only
====================================

Create a file named: .env.development
In the server/ folder with these contents:

NODE_ENV=development
PORT=5000
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=
DB_NAME=taraki_db
JWT_SECRET=dev-secret-key-12345
CORS_ORIGINS=http://localhost:3000,http://localhost:5000

====================================
NOTES:
====================================

- This is for LOCAL development only (XAMPP)
- Never use these values in production/Railway
- The DB_PASSWORD is empty (default XAMPP)
- CORS allows localhost access
